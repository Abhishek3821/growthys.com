# growthys.com

A responsive Next.js website with a rotating hero, service sections, interactive cards, investor tabs, FAQ, CTA, and footer.

Newsletter and signup forms currently provide UI only; external submission services are not connected.

This project was bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

Run `npm run build` for a production build and `npm start` to serve it. Local image assets are in `public/images`; their generation prompts and notes are in `docs`.
