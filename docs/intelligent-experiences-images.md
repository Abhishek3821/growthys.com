# Intelligent experiences artwork

Generated with the built-in Imagegen tool using the supplied screenshot as a visual reference. These are recreated abstract visuals, rather than the original source images.

Final project assets:

- `public/images/intelligent-experiences/topaz.webp` — 1200 × 1000, 207 KB.
- `public/images/intelligent-experiences/cobalt.webp` — 1200 × 1000, 242 KB.
- `public/images/intelligent-experiences/aster.webp` — 1200 × 1000, 147 KB.

The project uses quality-89 WebP conversions. Original generated PNG files remain in the tool's generated-images directory.

Component: `app/components/intelligent-experiences.tsx`.
Styles: `app/components/intelligent-experiences.module.css`.

The layout and displayed text reproduce the user-supplied reference. The Services navigation anchor opens this section, I'm Curious scrolls to the cards, and Learn More links to the official Infosys Cobalt page.

Validation: Next.js production build, TypeScript, and whitespace checks passed. In-app browser discovery returned no available browsers, so visual layout and click behavior were not browser-verified.
