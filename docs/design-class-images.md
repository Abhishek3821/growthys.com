# Design class illustrations

Created using the built-in imagegen tool. The generated sheet is exported into three WebP images using `scripts/prepare-design-class-images.cjs`.

Assets:
- `public/images/website-design/classes/ui-ux.webp`
- `public/images/website-design/classes/motion-graphics.webp`
- `public/images/website-design/classes/visual-identity.webp`

Final prompt:

Create ONE contact sheet of three colourful 3D illustrations stacked vertically in exactly 3 equal horizontal rows, no gaps, no borders, no text or letters, no UI card frames. Overall portrait aspect ratio 16:27, each row a landscape 16:9 illustration. Style: playful polished clay-render 3D educational design graphics, vivid purple backgrounds, yellow orange accents, turquoise and pink elements, soft shadows. Top row: a miniature designer standing at a desk with laptop, surrounded by oversized website interface panels, typography shapes, a stylus, a tiny plant and colourful rounded app blocks; friendly design workspace. Middle row: close-up motion graphics workstation, a large blue grid canvas on monitor with an animated abstract golden shape, a hand holding stylus, floating colour wheel, a timeline with coloured keyframes, chunky toggle switches and colourful UI controls. Bottom row: a large laptop displaying abstract brand identity artwork, geometric orange circles, small branding stationery, a miniature designer standing beside the laptop, oversized overlapping colourful swatch cards on right. Each scene centered and fills its own row, all three must be separate illustrations with precise straight row boundaries. No lettering, no words, no watermark.
